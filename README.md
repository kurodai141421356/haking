# BLACKBOX DEEP CTF v2

架空のWebアーカイブを調査する、サーバー検証式のCTFゲームです。目安は2〜3時間ですが、プレイ時間は調査経験によって変わります。

## 起動方法
1. Node.js 18以上をインストール
2. このフォルダーで `npm install`
3. `npm start`
4. ブラウザーで `http://localhost:3000` を開く

## 主な改善点
- 正解判定をブラウザー側JavaScriptからサーバー側へ移動
- フェーズ順をサーバー側で管理し、未解除ステージへの直接アクセスを拒否
- セッションごとの進行状況・ヒント回数を管理
- 3段階のヒント、スマホ対応UI、進行状況表示
- 調査対象は架空データ。外部サービスへの攻撃や実在サイトの探索は不要

## デプロイ
RenderなどではWeb Serviceとして登録し、Build Command=`npm install`、Start Command=`npm start`。`SESSION_SECRET`には長いランダム文字列を環境変数で設定してください。複数インスタンス運用や再起動後も進行を保持したい場合は、永続セッションストアとデータベースを追加してください。

## セキュリティ上の注意
これは学習用のCTFです。正解はサーバーコードにあるため、サーバー自体のソースを読める管理者は正解を確認できます。プレイヤーにはリポジトリのサーバーコードを配布せず、サーバーを別サービスとして運用してください。公開用に使う場合はセッション秘密鍵を必ず変更してください。
